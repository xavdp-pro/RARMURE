## Interpretation limits

The prose in [Architecture](../ARCHITECTURE.md), [Cooperation](../AGENT-COOPERATION.md), and [Validation](../REQUIREMENTS-AND-VALIDATION.md) defines the intended system.

- Diagrams simplify event delivery and assessment cycles. Reviews and experiments may repeat or overlap; visual adjacency does not impose a global scheduling barrier.
- Provider routing supplies authorized execution and context. A provider response does not directly become accepted code; applicable counter-review, validation, and master promotion remain required.
- Colors indicate illustrative contributions, not exclusive ownership of branches or fixed provider assignments.
- Only the master has direct agent read/write access to the present. Workers develop separate mutable working views in RAM. Fixed candidates and their test projections do not change while assessed; further edits create successors.
- The exploration graph represents successive transformations separately from code containment. A successful checkpoint does not validate all descendants or a composition.
- Assessment cards depict hypothetical evidence states, not tests that were run. A retained performance or security profile must meet shared mandatory criteria; profiles are alternatives rather than mandatory sequential stages.
- Language extensions, file paths, and role descriptions are examples rather than product commitments.
- Latent communication remains separate deferred research.
- Real-time means intended live coordination as work evolves, not a demonstrated deadline or latency guarantee. Fractal means a recurring cooperation pattern, not an exact fractal dimension.
- Non-exclusive intentions mean concurrent exploration without ownership locks. They do not demonstrate a mutex-free, lock-free, or wait-free runtime; internal synchronization remains an implementation choice. Assessment labels alone never authorize promotion.
- SHAPER supplies design inspiration. No SHAPER installation, service connection, or deployment is required for RARMURE to function independently.
